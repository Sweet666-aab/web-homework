# 第二次作业：用户注册页面

## 一、作业内容
制作一个完整的"用户注册"页面，综合运用 HTML 中的**列表**、**表格**、**表单**三大模块知识，并使用语义化标签构建页面结构。

## 二、使用到的标签

### 1. 语义化结构标签
- `<header>`：页面头部，包含网站标题和导航
- `<main>`：表单主体区域
- `<footer>`：页面底部版权信息
- `<h1>`：页面主标题
- `<section>`、`<nav>`、`<fieldset>`、`<legend>` 等语义标签

### 2. 表单相关标签
- `<form>`：表单容器，使用 `id="registerForm"`
- `<input>`：多种类型输入框
  - `text`（用户名）、`password`（密码/确认密码）
  - `radio`（性别）、`checkbox`（兴趣爱好）
  - `date`（出生日期，HTML5 新增）
  - `email`（邮箱，HTML5 新增）
  - `tel`（手机号，配合 `pattern` 正则校验）
  - `file`（头像上传，支持 `multiple` 多选）
- `<label>`：两种用法都使用了（`for` 属性关联 / 包裹 input）
- `<select>` + `<option>`：所在城市下拉选择，北京默认选中
- `<textarea>`：个人简介多行文本
- `<button>`：提交（`submit`）和重置（`reset`）按钮

### 3. 表格标签
- `<table>`、`<thead>`、`<tbody>`：划分表头与表体
- `<th>`：表头单元格
- `<td>`：普通单元格
- `rowspan="2"`：第一列"权益类型"纵向合并两行
- `colspan="2"`："普通会员"/"VIP会员"横向合并两列

### 4. 列表标签
- `<ul>`：无序列表，用于"注册流程"和"注意事项"
- `<ol>`：有序列表，用于"注册步骤"说明
- `<dl>` + `<dt>` + `<dd>`：定义列表，用于"常见问题"

## 三、表单验证与数据收集
- 使用 `required` 属性实现用户名、邮箱的必填校验
- 使用 `pattern="[0-9]{11}"` 实现手机号 11 位数字正则校验
- 使用 `placeholder` 提供密码输入提示
- 通过 JavaScript 监听表单 `submit` 事件，使用 `FormData` 收集所有控件数据，并在浏览器 Console 中打印

## 四、遇到的困难及解决方法

| 困难 | 解决方法 |
|------|----------|
| 兴趣爱好（checkbox）多个值如何收集 | 使用 `FormData` 遍历时，判断同名 key 是否已存在，若存在则转为数组存储 |
| 文件上传（file）类型在 FormData 中是 File 对象，不便查看 | 额外通过 `avatarInput.files` 获取文件列表，仅提取文件名打印 |
| label 的两种用法容易混淆 | "男"使用 `for` 属性关联 id，"女"使用 `<label>` 包裹 `<input>`，明确区分 |
| 表格合并单元格对齐问题 | 通过 `rowspan` 和 `colspan` 组合使用，确保表头与表体列数对齐 |

## 五、使用说明
1. 在浏览器中打开 `index.html`
2. 按 `F12` 打开开发者工具，切换到 Console 面板
3. 填写表单后点击"注册"按钮，即可在 Console 中看到收集到的数据
